   ----------------

   الطريقة الثانية (يدوياً):
   Method 2 (Manual):
   
   cd clinic
   git remote add neworigin https://github.com/amer-87/ClinicApp.git
   git push neworigin --all
   git push neworigin --tags
   git remote remove origin
   git remote rename neworigin origin
